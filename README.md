# ESSHUTTR — Amy Shephard Photography

A responsive portfolio redesign for Amy Shephard (Esshuttr), focused on live music photography, artist portraits, moving image and illustration.

## Run locally

```bash
npm install
npm run dev
```

Vite serves the site on `http://localhost:5173` by default. `npm run build` creates a production build in `dist/`.

The supplied Esshuttr logo artwork is stored at `public/esshuttr-logo.png` and used in the header, hero, footer, and browser icon. Portfolio photography remains loaded from Amy's existing Adobe Portfolio CDN. Gallery filters and the image lightbox are client-side; booking enquiries link to the existing contact form until a new form endpoint is configured.
